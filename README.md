# Lab Task 05 — Designing Specifications

## Objective

Apply concepts of method specifications, behavioral equivalence,
fail-fast precondition validation, mutation contracts, immutability,
and declarative specifications using Java and JUnit 5.

## Tasks Completed

1. Behavioral Equivalence
2. Failing Fast on Precondition Violations
3. Mutation Contracts
4. Immutability for Safer Contracts
5. Declarative vs. Operational Specifications

## Technologies Used

- Java
- Maven
- JUnit 5
- NetBeans IDE

## How to Run

1. Open the Maven project in NetBeans.
2. Build the project.
3. Open the Test Packages section.
4. Run the JUnit test classes.
5. Verify that all tests pass.
